# P143 自在之所 · Somewhere to Be

V0.033。以「自在之所 Somewhere to Be」地圖選擇想前往的想像空間，目前開放海邊小屋、寂靜寺院、雪山暖屋、都會陽台與松風庭園。本版預設為照片質感的寫實室內視景，可有限範圍拖曳查看、固定位置換位與聽音樂。

## 使用

預設寫實視景採用 AI 生成圖片，並非自由走動的 3D 模型。點下方按鈕或畫面中相應位置換位，拖曳／方向鍵查看左右上下。右上角「？」可切換舊 3D 模型實驗版或其他畫面模式。

以下自由走動與地板操作適用於 3D 模型模式。

- 進入後拖曳轉頭；WASD／方向鍵走動，或點地板前往。
- 使用下方按鈕前往唱機、沙發與窗邊。手機以目的地按鈕移動。
- 三張封套預設播放 Music/P143-01.mp3（爵士）、P143-02.mp3（古典鋼琴）與 P143-03.mp3（水晶）。可另選本機音樂，並可個別恢復預設。
- 另選的個人音樂保存在 IndexedDB，不上傳伺服器；重新開啟時優先使用。無法保存時會告知只供本次使用。
- 單一 audio 元素播放，換片停止上一首；單曲循環。預設 MP3 在按下播放時才載入，進屋不會自動播放音樂。
- 海浪是本機合成環境聲，與音樂可分別調整及完全靜音。
- 坐下時淡出切換相機；閒置後淡出介面，輕點喚回。
- 不支援 WebGL 2 的裝置自動顯示從實際模型輸出的固定視角預覽。右上角「？」可選擇即時 3D 優先、模型預覽或柔和靜景；切換會重新進入小屋。固定預覽及靜景均不提供自由走動。

## 場景

寫實室內是有限範圍的影像視景，並非 360 度重建。以下 3D 幾何描述適用於保留的模型實驗版。

真正的 Three.js 3D 室內，約 6 × 5 × 2.8 m；物件與相機共用單一場景。窗外為依選定概念稿延伸生成的海景素材，在海面局部以 shader 加入細微變化，並非實拍影片。室內為程序建模的原型，精細度與概念圖不同。

本儲存庫根目錄可直接由 GitHub Pages 發布為靜態網站。Three.js 0.180.0 的模組一併包含，不必在執行時載入外部程式。字體使用 Google Fonts，無法連線時使用系統字體。

## V0.032 花蓮晨昏光景

五個場所統一依花蓮日期與 Asia/Taipei 時間運作，不受使用者裝置時區影響。SunCalc 1.9.0 在本機推算每日太陽上緣日出日落，使用中央氣象署花蓮參考座標；不需要 API、資料庫或年度下載。日出前後各半小時由夜景經現有暖光轉為日景，日落反向；日間與夜間保持各自端點。自動模式按連續時間計算，不再疊加舊版五分鐘區間插值。

手動選時立即換光並凍結選定時間與日期；切回自動時取得花蓮當下日期時間，以 300 秒接回持續前進的光景。光景面板顯示日期、日出日落與「光景基準：花蓮｜天文推算｜台灣時間（UTC+8）」。日出日落快捷鍵也依當天計算更新。沿用所有照片，不是物理日照或天氣模擬。

暫停載入黑貓並隱藏閱讀、設定中的相關控制；原始程式、素材及既存陪伴偏好保留。音樂、自選檔案、閱讀與保持螢幕開啟功能沿用。

`node scripts/check-solar.mjs` 驗證五套光景、跨日跨年、三種裝置時區、手動暫停及自動銜接。2026 年四季代表日期共八個官方日出日落時刻，最大差距 2.329 分鐘，未加校正；這是抽樣結果，不是全年誤差保證。資料與來源見 [驗證記錄](docs/verification-v0032.md) 及 [官方樣本](docs/solar-reference-v0032.json)。SunCalc 的 BSD-2-Clause 授權隨附於 assets/vendor/。
