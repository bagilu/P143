# P143 海邊小屋 · Quiet Seaside Cabin

互動原型 V0.010。完全獨處的海邊木屋，可挑唱片、坐下看海。本版預設為照片質感的寫實室內視景，可有限範圍拖曳查看、固定位置換位與聽音樂。

## 使用

預設寫實視景採用 AI 生成圖片，並非自由走動的 3D 模型。點下方按鈕或畫面中相應位置換位，拖曳／方向鍵查看左右上下。右上角「？」可切換舊 3D 模型實驗版或其他畫面模式。

以下自由走動與地板操作適用於 3D 模型模式。

- 進入後拖曳轉頭；WASD／方向鍵走動，或點地板前往。
- 使用下方按鈕前往唱機、沙發與窗邊。手機以目的地按鈕移動。
- 三張封套各自綁定一個本機音樂檔；支援 MP3，其他格式依瀏覽器解碼能力。
- 音樂保存在 IndexedDB，不上傳伺服器。無法保存時會告知只供本次使用。
- 單一 audio 元素播放，換片停止上一首；單曲循環，沒有內建音樂。
- 海浪是本機合成環境聲，與音樂可分別調整及完全靜音。
- 坐下時淡出切換相機；閒置後淡出介面，輕點喚回。
- 不支援 WebGL 2 的裝置自動顯示從實際模型輸出的固定視角預覽。右上角「？」可選擇即時 3D 優先、模型預覽或柔和靜景；切換會重新進入小屋。固定預覽及靜景均不提供自由走動。

## 場景

寫實室內是有限範圍的影像視景，並非 360 度重建。以下 3D 幾何描述適用於保留的模型實驗版。

真正的 Three.js 3D 室內，約 6 × 5 × 2.8 m；物件與相機共用單一場景。窗外為依選定概念稿延伸生成的海景素材，在海面局部以 shader 加入細微變化，並非實拍影片。室內為程序建模的原型，精細度與概念圖不同。

本儲存庫根目錄可直接由 GitHub Pages 發布為靜態網站。Three.js 0.180.0 的模組一併包含，不必在執行時載入外部程式。字體使用 Google Fonts，無法連線時使用系統字體。

## 原始模型預覽重建（Sites 開發環境）

`node scripts/render-model-preview.mjs sofa 960` 從目前 `dist/app.js` 的場景建立區塊輸出模型預覽。開發端需安裝 `@napi-rs/canvas`，或使用設定好的 Codex runtime；線上網站不依賴此套件。可將 sofa 改為 entry、records 或 window。`docs/model-preview-provenance.json` 保存輸出時的場景程式雜湊。

## V0.006

保留寫實室內，加入遮罩內的程式水面微動、可停止動態與記住聲音偏好。唱片載入後可一鍵「播放並坐下」。海面效果不是實拍影片。

## V0.007

海面改用連續深度的浪紋位移，加入約 9 秒的湧浪與 38 秒的緩慢進退感。聲音面板可調整海浪起伏（預設 70%），偏好會保存；仍可關閉，減少動態設定優先。這是視覺模擬，不是實際潮位或實拍影片。

後續規劃：約 12 種時段光線；19:00–翌日 05:00 為星光黑夜，需連同室內燈光與窗景一致製作。這版尚未實作。

## V0.008

「光景」新增十二個固定時段，可自由手動選擇，重新進入會保留。新增日間與星夜三個視角的照片素材，共六張；以三組畫面配合亮度、飽和度與輕微色調延伸十二種氛圍，並非十二組獨立實拍或物理日照模擬。19:00、21:00、00:00、03:00 與 05:00 均使用星光夜景與室內暖燈。時間不隨真實時鐘自動前進。

保持當前位置與拖曳方向；換位沿用時段。海面紋理隨圖片更換，避免日間水面覆蓋夜景。切換前預載並保留舊圖，失敗可重試。光景功能適用預設寫實照片模式。

## V0.009

光景改為 00:00–23:59 的逐分鐘滑桿。每次載入以裝置當地系統時間啟動並持續跟隨，無需排程或伺服器；不沿用舊版儲存的手動時段。手動拖曳暫停跟隨，約 300 秒以 smoothstep 從目前混合狀態過渡至目標，期間再選時亦從眼前狀態開始。勾選「跟隨現在」同樣平滑返回當下時間。

十二組亮度／光色參數以循環時間插值連續呈現，三組照片以權重混合，跨午夜無跳變。19:00–翌日 05:00 使用星夜照片；05:00–06:00 與 18:00–19:00 分別漸入晨光與夜色。各照片使用同源水面動畫與獨立遮罩 ID，換位保留光景進度。這仍為光景模擬，非天文日照或真實地理位置的日出日落。

驗證包括虛擬時鐘的完整 300 秒漸變、跨日、途中重選、恢復跟隨，以及瀏覽器內滑桿、實際混合權重變化與漸變途中換位。

## V0.010

手動滑桿立即呈現選定時刻並暫停時鐘，同時取消尚未完成的自動漸變；海浪與音樂保持運作。切回「跟隨現在」時，以當下裝置時間為目標，約 300 秒平順接回，目標在過渡期間仍隨真實時間前進。自動模式的連續光景以五分鐘區間平滑插值，跨午夜與區間交界無突變；每次重新載入仍直接以現在的時間啟動。

驗證包含手動立即換光與長時間暫停、途中取消自動漸變、切回當下時間與持續前進、五分鐘過渡完成、自動區間交界連續性。
