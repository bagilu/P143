# P143 自在心圖 · V0.012

專案總名：自在之所 Somewhere to Be。世界入口：自在心圖 The Map Within。

地景資產：`assets/world-map-v0012.png`，1672 × 941。以內建影像生成功能製作，為虛構地域的寫實空拍風景。網頁文字、地點與手繪虛線為獨立 HTML / SVG 元件，圖片本身沒有文字。

生成設計：同一片地景包含左側海灣與礁岸小屋、中央森林裡的東亞佛教寺院、右上高山雪線木屋，以及右下河口平原城市。河流由雪山經森林流向海灣；建物、植被、海水、山岩皆採自然攝影材質，使用柔和午後日光。避免插畫、繪畫、模型、浮島及任何文字或地圖符號。

地點註冊：`world-map-model.js` 的 PLACES。座標是資產中的相對位置，非真實經緯度。正式開放項目需有 status=open 與 href；籌備中地點僅顯示介紹。

返回連結：海邊小屋 `seaside.html` → 根目錄心圖。返回時淡出唱片與環境聲，新頁面不執行小屋的音訊與 3D 迴圈。偏好與個人曲目仍保留在原有瀏覽器儲存空間。
