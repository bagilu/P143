# V0.042 持續音樂與圖片選曲

## 行為

地圖是持續存在的外層，同源 iframe 顯示場所。全站只有一個外層音樂元素；各場所透過 music-bridge 使用它，保留各自歌單、音量、自選音檔與 IndexedDB。離開場所停止環境聲，音樂帶回地圖；地圖提供曲名與播放／暫停。打開其他場所歡迎畫面仍播放，按「進入」後以約200ms淡出舊音樂，再釋放舊場所。重新整理整頁會重置音樂。

播放中的來源場所會保留到停止，以維持該來源的自選 blob URL。未取得播放器所有權的場所不能改變舊音樂音量、暫停或清空音源。同一場所從地圖返回時恢復環境聲，保留音樂狀態與進度。直接場所網址導入外層；standalone=1 保留獨立測試模式。

五處音樂都有既有場景圖片，點圖播放／暫停；獨立播放按鈕不顯示，自選／恢復仍在曲目選項。陽台四位置的移動按鈕隱藏，保留邊界拖曳。

## 驗證

Chrome 桌機預覽：陽台點圖片播放，圖片顯示暫停狀態；回地圖時 currentTime 由10秒持續至22秒以上且 paused=false。地圖暫停與返回原場所可操作。打開暖屋歡迎畫面時音樂仍播放（33秒以上），按進入後音源清空、paused=true。庭園與海邊小屋亦驗證圖片播放及回地圖延續。寺院保留兩個自選音檔入口，未選音檔時圖片為停用狀態。歡迎畫面的返回地圖不產生巢狀地圖。

自動檢查：check-music-bridge、check-sound-panel、check-sds、check-reading、check-screen-awake、check-solar、check-world-map、check-balcony-edge。共用媒體測試包含音源所有權、未啟用場所隔離、事件、音量／進度與本機blob來源。
