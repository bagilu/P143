# P143 虹橋茶樓沉浸場景 V0.053

## 內容

- 以茶樓窗邊視角呈現虹橋、河道與汴梁街市，加入日光、暮光、夜光三張寫實場景。
- 初次載入及「跟隨時段」依本機時間切換；手動選擇任一光景後暫停自動切換。
- 茶樓前景茶杯為返回熱點：從站內進入時返回進入前頁；直接開啟時返回虹橋原畫頁。
- 從原畫漫遊頁的「進入畫中景色」按鈕進入。
- 目前尚未把入口放到寺院場景的具體物件上；後續可在確認寺院隱藏位置後接入。茶杯返回採瀏覽歷史，從寺院進入時可回到寺院原位置。
